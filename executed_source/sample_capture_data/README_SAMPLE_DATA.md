# V360 sample capture data

This synthetic dataset is included only to validate the standalone audit generator.

- `flat/Ideal_Reference`: complete D-1 to D-6 ideal reference.
- `flat/Customer_Captures`: flat `D-<stone>-<machine>` layout. Machines 01–03 are complete; Machine 04 intentionally has only 5/6 captures.
- `flat/V50_Reference` and `flat/V50_EDF_Reference`: optional upgrade comparison tiers.
- `nested/Customer_Nested`: nested `Machine/D-<stone>` layout for folder-detection testing.

The still images and values are generated demonstration content, not calibrated production measurements.
